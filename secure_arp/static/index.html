What the monitor protects

Standard mode checks observed IP–MAC mappings. Secure mode also validates authenticated replies and rejects repeated messages. Learned MAC changes always require review.

This application observes traffic and protects its own trust table. It does not enforce the operating system’s ARP cache or add authentication to ordinary devices.

Notifications appear only for new critical events while this dashboard is open, with a cooldown between alerts. Enable desktop notifications and sound separately from Event history.
